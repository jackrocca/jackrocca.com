# NFL team logos

Original transparent PNGs from ESPN's NFL team directory, retrieved September 8, 2026. Filenames use ESPN team IDs, matching the league schedule. Artwork is preserved without cropping or recoloring. Next.js serves optimized sizes for the display. NFL team names and logos belong to their respective owners.

Source directory: https://site.api.espn.com/apis/site/v2/sports/football/nfl/teams?limit=32
