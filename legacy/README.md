# Archived Streamlit application

The original Python app, historical CSVs, automation documentation, and scheduled workflow definitions are preserved in `streamlit/` for reference. They are not a supported runtime, do not deploy to Vercel, and are excluded from current checks. Workflow YAML here is intentionally outside `.github/workflows`, so it cannot run from this branch.

The supported application is the root Next.js app. Current scoring, storage, and Google sign-in use the TypeScript implementation. Do not reuse legacy credentials, account records, or collectors for the 2026 league.
